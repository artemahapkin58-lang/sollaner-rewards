# Sollaner Rewards — первая версия

## Что умеет
- Начисляет 1 балл за текстовое сообщение в группе, не чаще раза в 60 секунд.
- Ограничивает начисление 20 сообщениями в сутки на участника.
- Даёт ежедневный бонус `/daily`.
- Показывает `/profile`, `/top`, `/rewards`.
- Создаёт заявку `/redeem ID` и отправляет её администраторам.
- Администратор одобряет или отклоняет заявку кнопками. При отклонении баллы возвращаются.

## Важно про подарки
Одобрение заявки пока НЕ отправляет Telegram-подарок автоматически. После одобрения администратор вручную отправляет подарок пользователю в Telegram. Это сделано намеренно: доступность подарков и возможность отправки ботом зависят от текущих возможностей Bot API и баланса бота. Не обещайте пользователю автоматическую выдачу до отдельной проверки.

## 1. Создай бота
Через @BotFather создай бота и сохрани токен в секрете. Никому не отправляй токен и не публикуй его в чате.

## 2. Узнай свой Telegram ID
Запусти бота, напиши ему `/myid`, скопируй числовой ID. Добавь его в переменную окружения `ADMIN_IDS` на хостинге.
Если бот ещё не запущен, можно узнать ID через надёжного ID-бота, но перепроверь число.

## 3. Добавь бота в группу
- Добавь бота в групповой чат Sollaner.
- Дай ему право читать сообщения (обычно достаточно добавить бота и отключить Privacy Mode).
- В @BotFather: `/mybots` → выбери бота → Bot Settings → Group Privacy → Turn off.
- Если менял Privacy Mode, удали бота из группы и добавь заново.
- Не выдавай боту права администратора, если они не нужны. Для подсчёта сообщений админ-права не требуются.

## 4. Разверни на Render
Самый простой путь:
1. Создай GitHub-репозиторий и загрузи файлы проекта.
2. На Render выбери New → Blueprint и подключи репозиторий с `render.yaml`.
3. В Environment добавь `BOT_TOKEN` и `ADMIN_IDS`.
4. Запусти Worker.

Для постоянного хранения SQLite нужен платный persistent disk/план Render. Не используй эфемерную файловую систему для реальной базы: данные могут пропасть при перезапуске или деплое.

## 5. Проверка
1. Напиши боту `/start` в личке.
2. Добавь бота в группу.
3. Отправь несколько обычных текстовых сообщений с интервалом не менее минуты.
4. Проверь `/profile`, `/top`, `/daily`, `/rewards`.
5. Для теста обмена набери нужное количество баллов и отправь `/redeem 1`.
6. Проверь уведомление администратора и кнопки одобрения/отклонения.

## Настройки
- `MESSAGE_COOLDOWN`: секунд между начисляемыми сообщениями.
- `DAILY_LIMIT`: максимум начислений за день.
- `DAILY_BONUS`: ежедневный бонус.
- `REWARD_COST`: цена первой и второй награды (вторая стоит в 3 раза дороже).
- `ADMIN_IDS`: числовые Telegram ID администраторов через запятую.
- `GROUP_ID`: необязательно; если заполнено, баллы начисляются только в указанной группе.

## Ограничения первой версии
- Баллы начисляются за текстовые сообщения; медиа и команды не учитываются.
- Защита от накрутки базовая, не заменяет ручную модерацию.
- Один бот следует запускать только в одном экземпляре polling, иначе возможны конфликты.
- Бот не должен собирать лишние персональные данные.
